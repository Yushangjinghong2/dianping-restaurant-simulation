# Dianping Restaurant Simulation

A prototype for simulating restaurant choice, dining, and review participation with customer and restaurant agents. The repository contains the simulation code and an initial portrait pool (20 restaurant profiles and 120 customer profiles).

## Data and privacy

The portrait files are derived from the merged research dataset. Customer identifiers are preserved as supplied in the source and have not been anonymized. Raw review text and the full source dataset are not included in this code repository; the full dataset is on [Hugging Face](https://huggingface.co/datasets/yushangjinghong/dianping-three-source-merged). See [PROJECT_PROGRESS.md](PROJECT_PROGRESS.md) for project status and [data/initial_portraits](data/initial_portraits) for the profiles.
