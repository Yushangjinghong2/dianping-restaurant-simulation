# Dianping Restaurant Simulation

A prototype for simulating restaurant choice, dining, and review participation with customer and restaurant agents. The repository contains the simulation code and a small, anonymized initial portrait pool (20 restaurant profiles and 120 customer profiles).

## Data and privacy

The portrait files are derived from the merged research dataset. Customer identifiers are preserved as supplied in the source; no ID remapping or review-text transformation has been applied. Raw review text and the full source dataset are not included in this code repository. See [PROJECT_PROGRESS.md](PROJECT_PROGRESS.md) for the current project status and [data/initial_portraits](data/initial_portraits) for the profiles.
